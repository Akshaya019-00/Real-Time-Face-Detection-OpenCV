# Real-Time Face Detection Using OpenCV

## Project Overview
Developed a real-time face detection application using Python and OpenCV to identify human faces from a live webcam video stream.

## Technologies Used
- Python
- OpenCV
- Haar Cascade Classifier
- Webcam

## Key Features
- Real-time face detection.
- Live webcam video processing.
- Face identification using Haar Cascade.
- Bounding boxes around detected faces.

## How to Run
1. Install Python.
2. Install OpenCV using `pip install opencv-python`.
3. Run the Python application using `python main.py`.
4. Allow webcam access to start face detection.

## Project Objective
To demonstrate real-time computer vision and image processing using OpenCV.
